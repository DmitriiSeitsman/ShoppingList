# <h1 align="center">СПИСОК ПОКУПОК</h1>

ShoppingList — приложение для создания и ведения списков покупок.
Разработано на SwiftUI с использованием чистой архитектуры MVVM и современного фреймворка хранения данных SwiftData.

⚙️ Технологический стек  
-UI: SwiftUI  
-Архитектура: MVVM  
-Асинхронность: async / await  
-Локальное хранение: SwiftData  
-Код-стайл: SwiftLint  
-Swift: 6.0  
-Минимальная iOS: 17.0

✨ Основные возможности
Создание и редактирование списков покупок
Добавление товаров с категориями и цветами
Сортировка и фильтрация
Удобный минималистичный интерфейс
Полная офлайн-работа
